# Регламент рейтинга

Источник истины: [Гид по РЕРЕЙЗ — Регламент рейтинга](/faq?tab=rating-rules), контент в config/faq-content.ts. Синхронизировано с публичным FAQ.


## 1. Принципы

1.1. Рейтинг — внутренняя система результатов, не представляющая собой деньги, имущество, имущественные права или право на бесплатные/льготные услуги.
1.2. Итог сезона равен сумме очков участника за все рейтинговые мероприятия в период сезона.
1.3. Фактическое участие даёт **+2 очка** за турнир; повторные входы не создают повторно этот бонус.
1.4. Финал месяца и финал отбора рейтинга не дают.
1.5. В исторических турнирах сохраняется версия формулы, действовавшая на дату турнира; приведённые ниже правила описывают действующую версию v2 и не пересчитывают прошлые результаты.

## 2. Рейтинговая зона

Размер поля = число уникальных участников, фактически начавших турнир, **без повторных входов**.
Рейтинговая зона = `min(количество игроков, max(3, ceil(0.30 × количество игроков)))`.
Очки за место начисляются только внутри этой зоны. Остальные участники могут получить +2 за участие и предусмотренные форматом очки за нокауты.

## 4. Коэффициент размера поля

| Уникальных игроков | Коэффициент |
|---|---:|
| 2–7 | 0,70 |
| 8–11 | 0,85 |
| 12–15 | 1,00 |
| 16–19 | 1,10 |
| 20–24 | 1,20 |
| 25–29 | 1,30 |
| 30–35 | 1,40 |
| 36 и более | 1,50 |

При единственном участнике в техническом расчёте действует нижняя группа коэффициента, хотя условия проведения таких мероприятий определяются отдельно.

## 5. Учёт игрового объёма

Для целей формулы:

- `У` — число уникальных участников;
- `В` — общее количество фактических входов, включая первоначальные и повторные;
- `П = В − У` — количество повторных входов;
- `Д` — общее количество дополнительных входов.

Общий взвешенный объём = `В + 2 × Д`.
Дополнительный объём = `П + 2 × Д`.
Коэффициент объёма = `1 + 1,25 × Дополнительный объём / Общий взвешенный объём`.

Для Classic, Deep Stack, Win The Button, Crazy Pineapple, Bomb Pot, Free-Roll, Omaha / Hold'em Mix, Progressive Knockout, RERAISE Main Event и естественного расчёта Phoenix очки за место рассчитываются так:

`округление(базовые очки за место × коэффициент поля × коэффициент объёма)`.

Округление выполняется до ближайшего целого, половина округляется вверх. Если для Main Event или Phoenix задан дополнительный коэффициент мест, он применяется к уже округлённым естественным очкам за место с повторным округлением по той же схеме.

Для Bounty Hunters и Boss Bounty повторные входы **не увеличивают напрямую** коэффициент очков за место:

`коэффициент места = 1 + 1,25 × (2 × Д) / (В + 2 × Д)`.

`очки за место = округление(базовые очки × коэффициент поля × коэффициент места)`.

Для Mystery Bounty используется `округление(базовые очки × коэффициент поля)` **без коэффициента объёма**.

## 6. Дополнительные очки форматов

**Bounty Hunters:** обычный нокаут — **5 очков**.
**Boss Bounty:** обычный нокаут — **5**, нокаут Босса — **10**.
**Mystery Bounty:** после закрытия регистрации формируется пул `ceil((5 × В + 10 × Д) / 10) × 10`; из него создаются конверты. Они дают исключительно рейтинговые очки, не имущество. Число конвертов = количество активных участников на закрытии регистрации минус один.
**Progressive Knockout:** каждому входу соответствует начальный счётчик 6 очков. Половина счётчика выбитого (вниз при округлении) начисляется выбившему; остаток увеличивает счётчик выбившего. По завершении остаток счётчика победителя начисляется ему. При совместном нокауте судья явно распределяет доли в журнале. Стандартные +5 очков за нокаут в этом формате **не действуют**.
**RERAISE Main Event:** только очки за место умножаются на коэффициент конкретного мероприятия (типовое значение ×2).
**Phoenix:** если установлено гарантированное минимальное общее количество рейтинговых очков и естественный расчёт турнира ниже него, недостающая величина распределяется между местами рейтинговой зоны пропорционально естественным очкам за место по методу наибольших остатков. Фиксированные +2 за участие не умножаются.

## 7. Фиксация результатов и окончание сезона

7.1. Параметры рейтингового объёма и доступные игровые действия фиксируются по регламенту турнира при закрытии регистрации; если для турнира сохранён расчёт очков за места на этом этапе, он используется при итоговом завершении без повторного применения коэффициентов.
7.2. По завершении турнира система сохраняет очки за участие, место, нокауты и специальные механики в отдельном расчётном разбиении и в итоговой сумме.
7.3. При равенстве суммы очков игроки имеют равный результат. Если необходимо определить одного победителя сезона, решение принимают организаторы по объявленной процедуре; система не применяет несуществующий автоматический критерий.
7.4. Изменения формул применяются к новым турнирам и **не пересчитывают закрытую историю**.
7.5. Рейтинг и достижения не предполагают денежного или имущественного выигрыша, обмена очков на услуги клуба или иной коммерческой конвертации.
