## Recovery

Any transaction failure rolls back configuration, results, snapshot, achievement progress
and audit together. Keep the verified database backup and before-image protected.
Application rollback uses the previously verified immutable application image and
canonical compose, without database downgrade, migrations or full database restore.
After a committed correction, application rollback alone does not revert points.
If historical data restoration becomes necessary, stop and authorize a separately reviewed
inverse repository transaction against the recorded after-revision; never replay import,
subtract deltas blindly or restore the whole production DB.
